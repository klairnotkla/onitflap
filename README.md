# ONITFLAP

A small browser arcade game about loose heel flaps. Original vector shoe illustrations; no image assets or application dependencies.

Run `npm run dev` (Python 3 required), then open port 3000 in a browser. Swipe downward over a raised heel flap, or press the down arrow to fix the leftmost visible loose flap. The conveyor accelerates; fix as many flaps as possible in 60 seconds. Misses are counted but do not end the round. Personal best is saved locally, and sound is optional.

The page uses Google Fonts when available and local fallback fonts offline.
